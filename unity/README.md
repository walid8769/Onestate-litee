# OneState Litee — Unity 6 URP prototype

This is a separate Unity project scaffold. The existing Godot project remains untouched under `godot/`.

## Project
- Unity Editor: Unity 6 (6000.x)
- Render pipeline package: Universal Render Pipeline (URP)
- Platforms planned: iOS and Android
- Unity project root: `unity/`

## Important
This is a build-validation scaffold, not a finished game. It creates a simple test scene so Cloud Build can validate the Unity toolchain. Realistic vehicles, characters, animations, world streaming, multiplayer and roleplay systems must be developed and tested as separate milestones.

Open this folder as the Unity project root. Do not open the repository root as a Unity project.
