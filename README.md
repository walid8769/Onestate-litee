# OneState Lite

مشروع لعبة عالم مفتوح ثلاثية الأبعاد تعمل عبر المتصفح باستخدام Three.js.

## الحالة الحالية بوضوح

المستودع يحتوي على نموذج لعب ثلاثي الأبعاد، عالم مدينة مولّد، شخصية وتحكم لمس، وعميل اتصال شبكي. تمت إضافة خدمة WebSocket مبنية على Cloudflare Durable Objects لتقسيم جلسات ME1 وME2 وME3، مع حد أقصى مضبوط قدره 100 اتصال لكل غرفة على مستوى الكود.

**هذا لا يعني أن اللعب الجماعي أصبح منشوراً أو أن 100 لاعب تم اختبارهم.** خدمة Worker تحتاج نشر وربطاً، والنسخة الحالية لا تحتوي بعد على نظام حسابات آمن مكتمل أو سيارات ووظائف وشرطة ومستشفى واقتصاد نهائي. لا تستخدم بيانات حقيقية أو كلمات مرور في هذه النسخة.

## تشغيل الواجهة

واجهة اللعبة الحالية ثابتة ويمكن استضافتها على Cloudflare Pages من جذر المستودع. إعدادات البناء: Framework preset = None، Build command فارغ، Build output directory = `.`.

## نشر خدمة اللعب اللحظي

يتطلب ذلك نشر Worker منفصلاً من هذا المستودع باستخدام Wrangler:

1. أنشئ Worker جديداً واربطه بالمستودع أو انشر مجلد المشروع من بيئة تدعم Wrangler.
2. استخدم ملف `wrangler.toml` الموجود في الجذر.
3. انشر Worker بعد تفعيل Durable Objects ومراجعة ترحيل `GameRoom`.
4. اختبر `/api/health` ثم `/api/servers` على عنوان Worker.
5. في صفحة اللعبة، عرّف `window.ONESTATE_REALTIME_URL` بعنوان Worker الأساسي قبل تحميل `src/main.js`، مثال: `https://اسم-worker.حساب.workers.dev`.

حتى يتم ضبط هذا العنوان ونشر Worker، سيبقى مؤشر الاتصال «غير متصل» وتعمل الواجهة محلياً فقط.

## بنية البيانات

ملف `database/schema.sql` يعرّف جداول أولية للحسابات والملفات الشخصية والمركبات والوظائف وسجل الأحداث. لم يتم ربط هذه الجداول بخدمة مصادقة أو حفظ فعلي بعد؛ لا تعتبرها نظام حسابات جاهزاً.

## متطلبات الإصدار النهائي

- نماذج وشخصيات ومركبات ثلاثية الأبعاد أصلية مع حركات وتصادمات.
- قيادة المركبات والدخول والخروج منها.
- حسابات ومصادقة آمنة، حفظ تقدم وممتلكات.
- وظائف وأنظمة شرطة وإسعاف واقتصاد ومهام.
- مزامنة سلطوية للحركة والتحقق من الغش وإعادة الاتصال.
- اختبارات تحميل فعلية لكل سيرفر للتأكد من 100 لاعب متزامن مع قياس زمن الاستجابة واستهلاك الموارد.

لا يُعلن الإصدار نهائياً ولا تُعلن سعة 100 لاعب مدعومة قبل إنجاز واختبار هذه المتطلبات.
