# OneState Lite

مشروع لعبة عالم مفتوح ثلاثية الأبعاد تعمل عبر المتصفح باستخدام Three.js.

## تشغيل
فعّل GitHub Pages من إعدادات المستودع ثم افتح رابط الموقع في Safari. اختر ME1 أو ME2 أو ME3 واضغط «دخول المدينة».

## المرحلة الحالية
- واجهة عربية لاختيار السيرفر.
- مدينة مولدة إجرائياً تضم وسط المدينة، الحي السكني، المنطقة التجارية، المنطقة الصناعية والواجهة البحرية.
- شوارع رئيسية وأرصفة وعلامات طريق وأشجار وأعمدة إنارة.
- مبنى مركزي مميز.
- شخصية ثلاثية الأبعاد قابلة للحركة بعصا لمس، مع كاميرا خلفية وزر ركض.
- عرض اسم الحي الحالي في واجهة اللعب.
- تحسين إعدادات العرض لتناسب الهواتف.

## ملاحظة تقنية مهمة
هذه نسخة تطوير محلية وليست لعبة متعددة اللاعبين بعد. اختيار ME1/ME2/ME3 يغير واجهة الاختيار فقط ولا ينشئ خوادم منفصلة. لا يوجد حالياً تسجيل دخول أو مزامنة لاعبين أو خادم لعب. الوصول إلى 100 لاعب لكل سيرفر يحتاج بنية خوادم مستقلة، شبكة لحظية، إدارة جلسات، تخزين، حماية واختبارات تحميل. لا تعتبر سعة 100 لاعب متاحة حتى يتم تنفيذ هذه الأنظمة واختبارها فعلياً.
