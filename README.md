# OneState Lite

لعبة عالم مفتوح ثلاثية الأبعاد تعمل في المتصفح باستخدام Three.js، ومهيأة للنشر على Cloudflare Pages مع خدمة اللعب الجماعي على Cloudflare Workers + Durable Objects.

## ما هو موجود في المشروع الآن

- مدينة مفتوحة بشبكة طرق تقارب 700 متر، تسعة أحياء، مركز أعمال، سكن، منطقة تجارية وصناعية، واجهة ساحلية، حدائق ومواقف.
- مبانٍ خارجية مفصلة من نماذج GLB مرخصة CC0، مع مستويات تفاصيل LOD، وخامات PBR وإضاءة وسماء HDRI. يدعم المحمّل ضغط Meshopt وخامات KTX2.
- نموذج شخصية بشرية rigged مع حركات idle وwalk، ومزامنة لاعبين آخرين بسلاسة.
- سيارات سيدان، SUV، استيشن، أجرة، كوبيه، فان، إسعاف وحافلة، مع قيادة وعجلات متحركة، وبدائل مجسمة عند فشل تحميل نموذج خارجي.
- مشاة وحركة مرور آلية، كاميرا منظور ثالث، عصا لمس، ركض، خريطة مصغرة، HUD وركوب المركبات.
- ثلاث غرف مستقلة: ME1 وME2 وME3، مع فصل الرصيد والوظيفة والمستوى والخبرة والمهام وموقع الحفظ لكل سيرفر. حد الغرفة مضبوط على 100 اتصال في الكود، مع إرسال تحديثات الحركة 10 مرات بالثانية تقريباً وإظهار اللاعبين القريبين فقط لتقليل حمل الشبكة؛ هذا ليس نتيجة اختبار تحميل فعلي.
- محادثة محلية للاعبين القريبين مع تحديد طول الرسالة، تنظيف محارف التحكم وتحديد سرعة الإرسال لمنع الإغراق.
- حسابات بكلمات مرور مشتقة باستخدام PBKDF2، جلسات دخول، ملف شخصية محفوظ، رصيد ومستوى ووظيفة وآخر موقع موثّق للاعب لاستعادته عند العودة.
- مهام حسب الوظيفة مع نقاط وصول في المدينة، ومكافآت نقدية وXP؛ يتحقق الخادم من الجلسة والسيرفر وموقع اللاعب ومدة المهمة قبل منح المكافأة.

## ما لم يُثبت بعد

هذه نسخة تطوير متقدمة وليست إصداراً نهائياً معتمداً. لم يتم إجراء اختبار تحميل يثبت 100 لاعب متزامن لكل سيرفر، ولم يتم اختبار الأداء والشكل النهائي على أجهزة iPhone فعلية في هذه الجلسة. حركة المركبات وبعض التصادمات ما زالت محلية في العميل، ولا يوجد حتى الآن نظام كامل لمخزون اللاعب أو ملكية السيارات والمنازل أو اقتصاد شامل أو نظام صلاحيات إدارية لاعتماد الشرطة والإسعاف. لذلك لا تُعامل الوظائف الحساسة على أنها رتب إدارية حقيقية، ولا تُعلن سعة 100 لاعب كقدرة مثبتة قبل اختبارها.

## نشر الواجهة على Cloudflare Pages

اربط هذا المستودع بـ Cloudflare Pages باستخدام:
- Framework preset: None
- Build command: فارغ
- Build output directory: `.`
- Root directory: `/`

## نشر خدمة اللعب الجماعي على Cloudflare Workers

يوجد إجراء GitHub Actions باسم **Deploy OneState realtime Worker**:

1. أنشئ Cloudflare API Token بصلاحيات إدارة ونشر Workers وDurable Objects للحساب.
2. في GitHub افتح Settings → Secrets and variables → Actions، وأضف:
   - `CLOUDFLARE_API_TOKEN`
   - `CLOUDFLARE_ACCOUNT_ID`
3. افتح Actions → Deploy OneState realtime Worker → Run workflow.
4. بعد نجاح النشر افتح عنوان Worker وأضف `/api/health`. يجب أن يعيد حالة الخدمة وقائمة السيرفرات وسعة الغرفة.
5. انسخ عنوان Worker الأساسي إلى حقل «رابط خدمة اللعب الجماعي» في قائمة اللعبة مرة واحدة؛ تحفظه اللعبة محلياً.

لا يمكن إكمال خطوة إنشاء أسرار Cloudflare أو تشغيل النشر من دون صلاحية الحساب. GitHub commits وحدها لا تعني أن Worker أصبح منشوراً أو متصلاً باللعبة.

## بنية الملفات

- `src/main.js`: المشهد، الواجهة، التحكم، المركبات، المهام والتحديث.
- `src/world.js`: المدينة والمباني والطرق والمرور والمجسمات.
- `src/architecture.js`: مبانٍ إجرائية مفصلة كخطة بديلة عند تعذر تحميل GLB.
- `src/avatar.js`: تحميل الشخصية وحركاتها.
- `src/network.js`: اتصال WebSocket وإعادة الاتصال.
- `worker/index.js`: غرف اللعب والحسابات والمهام والتحقق الخادمي.
- `wrangler.toml`: Durable Objects migrations and bindings.
- `.github/workflows/`: فحص JavaScript وإجراء نشر Worker.
