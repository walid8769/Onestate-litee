# OneState Lite

مشروع لعبة عالم مفتوح ثلاثية الأبعاد تعمل عبر المتصفح باستخدام Three.js.

## تشغيل النسخة التجريبية
فعّل GitHub Pages من إعدادات المستودع ثم افتح رابط الموقع في Safari. اختر ME1 أو ME2 أو ME3 واضغط «دخول المدينة».

## الموجود حالياً
- واجهة عربية لاختيار السيرفر.
- مدينة أولية مولدة ثلاثية الأبعاد.
- شخصية قابلة للحركة بعصا لمس، مع كاميرا خلفية وزر ركض.
- تصميم متجاوب مع الهاتف.

## مهم
هذه نسخة تأسيسية محلية. اختيار ME1/ME2/ME3 واجهة فقط ولا ينشئ عوالم شبكية منفصلة. لا يوجد حالياً تسجيل دخول أو مزامنة لاعبين أو خادم متعدد اللاعبين. استيعاب 100 لاعب في كل سيرفر يحتاج خوادم لعب مستقلة، نظام شبكة لحظي، قاعدة بيانات، حماية واختبارات تحميل قبل اعتباره جاهزاً للإنتاج.
