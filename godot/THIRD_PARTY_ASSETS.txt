Third-party runtime assets
===========================

1. Generic compact SUV
   File fetched during iOS build as godot/assets/models/realistic_suv.glb
   Source: https://www.innerscene.com/tools/library/3d-parts/generic-compact-suv-9f157ee5
   License: CC0 1.0 (public domain dedication), as stated on the source page.
   Original unbranded, textured GLB model, approximately 4.5 x 2.2 x 1.7 m.
   The build validates the GLB header and rejects unsupported meshopt and
   mesh-quantization extensions before importing the model.

2. Realistic humanoid character
   File fetched during iOS build as godot/assets/models/realistic_character.glb
   Source: https://github.com/memoriesrohit/avatar-studio
   Source file: models/andre_casual.glb
   License: Microsoft Rocketbox Avatar Library, MIT; see the source repository's
   THIRD_PARTY_NOTICES.md for the full Microsoft notice.
   The GLB includes a rig and 13 motion-captured animation clips.

These assets are fetched at build time and bundled into the iOS app. They are
not downloaded by the game at runtime.
